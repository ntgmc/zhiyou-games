# 潮汐港：合约与对手

玩家经营白帆运输，与岑舟的船队共享港口。任务是交出有足够收入、资金可执行、双方合作激励成立的排班表。玩家选择合同、保证金、合作分账和自己的靠港行动；岑舟依据公开收益与策略独立决定，不读取玩家的隐藏行动。

## 单次互动与合同

收益矩阵依次存储双方错峰、白帆错峰而岑舟抢先、白帆抢先而岑舟错峰、双方抢先。每项都是双方收入。

- 每方签约前须有“保证金 + 手续费 + 最低运营周转”现金。
- 岑舟另外检查合作净收益是否至少达到替代航线收益。收益相等时愿意参与。
- 拒签后双方取得各自替代航线收益，无保证金、手续费或靠港行动结算。
- 接受合同后，每方都支付手续费。守约保证金当班全部返还，抢先保证金交给港务处。
- 周转资金是余额要求，不是再次扣除的费用。游戏忽略保证金的额外机会成本。
- 分账只在双方都错峰时执行。正数由白帆支付给岑舟，负数方向相反。
- 岑舟仅在错峰对其严格占优时错峰，否则抢先；相等时抢先。这是公开的保守策略，不是通用均衡求解器。
- 收益表预览计算“合同获接受后的收益”。正式执行额外检查对方参与与资金；拒签不执行该收益表。

玩家行动与对手策略、合同接受判定分开计算。反事实比较固定已揭晓的对手行动，再计算玩家另选一个行动的收益。记录每班条件、合同、双方动作、净收入、单方偏离收益与现金余额。

## 进阶与综合值班

第 9～12 章分别检验双向分账、对手的后续现金、累计担保和不同延续概率。第 13～16 章把这些条件放进更长排班。第 17～19 章换用新的外港报价、手续费和长期货价，要求重新检查既有规则的适用条件。第 20～24 章从十班扩展到二十四班，交接点的资金、分账和登记额度相互影响。收益、周转金、手续费与替代航线全部提前公开。

第十一章引入累计担保登记额度。玩家先做一次试算，观察保证金守约退回现金后，已登记额度仍占用的结果。之后进入自主排班。申请不得超过剩余登记额度；合同被接受后，按每方保证金金额累计计入。拒签不登记，也不扣手续费。额度是港务处为本次任务分配的登记容量，不是机会成本、额外现金支出或现实中的通用银行规则。

这些章节每班都要求实际错峰且双方合作激励成立，不能用拒签或高利润的违约跳过困难班次。担保上限是执行时的硬性约束，收入和合作是否达标只在结算检查；格式、当前资金和额度合法但损害未来的合同仍可提交。

第十章第一班不分账、保证金 5，可以让双方当班稳定合作，白帆赚 5，岑舟也赚 5。然而岑舟余额只到 14，第二班须有 17，会拒签。第十六章第六班采用保证金 5、分账 3，当前同样稳定，却只把岑舟余额带到 53；下一班参考合同须有 54。这些是实际模型中的后续失败，不是教程禁止某种合法选择。

第十六章第十二班本地较省的保证金 7、分账 −2，会少留一枚白帆现金，影响下一班签约。对每班合法稳定合作方案按“最低保证金，再取白帆最高利润”或“最高白帆利润，再取最低保证金”选择，都无法完成全天排班。固定一组保证金与分账同样无法通关。

第二十四章第一班若用保证金 5、分账 3，当班合作稳定且合法，双方现金为 20／23；下一班参考合同要求岑舟有 6 + 2 + 16 = 24，因此拒签。第 20、21、22、24 章中，两种局部贪心都在后续资金约束处停下；终关的全部 117 组固定合同也无法完成。玩家仍可自行选择其他方案：把终关第十六、十七班改为保证金 7、7，分账 −3、3，其余沿用参考方案，收入仍为 244，累计担保降到 164，可获三星；第一班单独多交 1 保证金，则用 167 的额度完成两星方案。

## 重复博弈

第六章使用标准收益：双方合作各 6，单方偏离者 9、另一方 1，双方抢先各 3。每轮结束独立以概率 p 继续，所有条件公开且固定。玩家可以公开触发策略：从合作开始，出现一次抢先后，双方以后一直抢先。

持续合作期望收益为 `R / (1 − p)`；偏离一次、以后双方抢先为 `T + pP / (1 − p)`。双方都无获利偏离时，岑舟使用合作策略；否则抢先。标准收益中 p 至少为 0.5 才有弱合作激励，p = 0.5 双方收益相等，不能解释为严格更偏好合作。

后续惩罚也必须可信；标准表中的相互抢先本身是单轮纳什均衡。正式关卡不开放任意收益与惩罚策略，防止把该公式误用为任意博弈的通用合作判定。

这里结算整个关系的期望收益，未抽取实际随机航次数，不计入现金账。实际玩家若选择偏离，模型结算一次偏离及之后的相互抢先。实验台允许改变 p，并把单轮均衡标签与长期激励比较分开展示。

第十二章给出三段独立关系，延续概率分别为 25%、50%、75%，其他标准收益不变。每段单独计算期望，相互之间不延续行动或惩罚，也不把期望计入现金。总目标要求两段稳定合作和期望收入 40，不能把所有报价都套用同一开始行动。

第十九章把四段独立关系的货价改为不同收益表。第一条线双方合作与违约期望都是 14，处于弱激励边界；第二条线白帆两种期望都是 12，岑舟则为合作 16、违约 18，不能只检查自己。第三条线沿用第二条的货价，把延续概率提高到 75%，双方合作期望 24／32、违约期望 18／24，可以维持合作。第四条线虽有 75% 延续概率，双方合作期望 20、违约 21，仍无法维持合作。四段互不延续行动或惩罚，期望不进入现金。

第七章的有限终点为共同知识，不把未来报复当作自动维持合作的理由，玩家须使用当班可执行的合同。未建模未知类型、风险偏好、额外折现、误判、随机违约或合同执行误差。这些限制在手册与任务中公开。

## 界面与保存

新玩家默认进入对话式剧情，每一步只显示当前需要的比较或试算。第一章先固定对方的行动，分别比较自己的两种收入；比较后才解释最佳回应与严格占优。第二章试保证金，第四章试分账，第五章试现金与周转要求，第六章试延续概率，第七章观察没有未来惩罚的最后一班。实验不会改变正式草稿、现金、提示记录或成绩，使用与正式排班相同的收益和结算规则。

剧情要求玩家实际比较或试算后再继续，但不要求试出参考金额。第三章、第八章与后续独立章节只说明订单，随后交回自主排班；第十一章在引入额度时有一次练习。已有规则、净收益表、完整后续条件与航运记录都能回看。整章订单总表标明已结算、当前待排和后续班次，集中列出双方收益、周转金、手续费与替代航线；重复关系还显示延续概率。页头和合同控件附近分别显示累计担保与剩余额度。

玩家可以主动切换完整调度桌，模式切换保留步骤、练习和草稿。调度桌不受教学步骤限制，返回剧情后继续原步骤；已经正式执行过的本章直接继续排班。重看本章剧情会从第一班重新开始，并清空本次尝试与练习，已有星级和独立成绩保留。入口附近说明重置范围。

结算先显示与本章任务相接的角色回应，再解释本次实际选择带来的收入、没收或拒签后果。失败列出未达到的收入与稳定合作班次。保证金、手续费、另一种行动和双方守约收入的计算按需展开；历史记录保留现金变化，便于追查影响后续班次的选择。

重复博弈首次使用公式时，先解释概率、百分比、期望收入、R、T、P 的含义和金币单位，再用当前数据计算。实验台也有这些说明，并明确单轮均衡与长期互惠的判定不同。独立章节没有推荐解法按钮，合法但激励不足的方案可以执行并失败。

行动、合法草稿、模式、剧情步骤、练习选择与试算结果自动保存。存档沿用独立键与版本，读取后从历史决策重演账目，并校验格式、次数与操作合法性。旧存档继续原排班，在调度桌恢复，不强制重做新增教程。当前航段损坏时重新开始该章，保留已通过校验的历史成绩。刷新保持当前复盘或下一班的草稿。章节切换保留各章的排班与草稿，返回后继续；重开或重看只重置本章当前尝试，已有成绩保留。存储异常不阻止游玩，但会显示不能保证刷新恢复的提示。

使用原生按钮、表单、折叠区与 dialog，支持键盘、窄屏和减少动画。没有外部字体、图像、接口、运行时依赖或账号服务。新增页面沿用已有多页面构建与子目录相对路径。
