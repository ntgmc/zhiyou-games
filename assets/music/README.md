# 知游 · 原创配乐

七首配乐由项目中的 `scripts/compose-music.py` 合成，包含各自的和声、旋律与立体声回响。没有使用第三方歌曲、录音采样或外部音源。

| 文件 | 曲目 | 使用场景 | 长度 |
| --- | --- | --- | --- |
| `orbit.mp3` | 轨道晨光 | 剧情开场、安静的航段介绍 | 53.33 秒 |
| `code.mp3` | 码间微光 | 前三章的实战练习 | 48.00 秒 |
| `storm.mp3` | 风暴边界 | 第四章起的实战、失败后的调整 | 41.74 秒 |
| `arrival.mp3` | 远方回声 | 成功回信、章节完成 | 56.47 秒 |
| `harbor.mp3` | 港口午后 | 潮汐港：钢琴、低音与轻扫拍点，带一点摇摆节奏 | 147.69 秒 |
| `workbench.mp3` | 台灯下 | 检修站：柔和电钢琴与稀疏的低音，适合边看报告边思考 | 164.57 秒 |
| `mountain.mp3` | 沿山而行 | 山城补给网：木质拨弦与笛声，节奏像沿着山路慢慢走 | 137.14 秒 |

以 44.1 kHz 立体声、112 kbps MP3 保存。合成时将释放包络和回响尾音卷回开头，网页通过 AudioBuffer 循环播放。只按需加载当前曲目，初始静音。通信站支持自动选曲与手动固定曲目：自动选曲跟随章节阶段，打开码树、实验和手册等工具窗口，以及中间轮次的发送与结算，均沿用正在播放的旋律。

潮汐港、检修站和山城补给网各使用一首主题曲，切换章节、剧情与操作界面、查看提示或结算时连续播放。三首主题曲各有八组乐句，第二遍减少伴奏或改变音区。页头的音乐面板提供开关和音量，各游戏分别保存偏好，存档备份不包含音乐设置。页面隐藏时暂停，返回后恢复；刷新后等玩家下一次交互再播放。

这些配乐可随本游戏复制、部署和公开播放，不需要额外购买第三方音乐授权。本说明只针对上述七个音乐文件，不替整个项目指定许可证。

重新合成需要 Python、numpy 和 ffmpeg（或 imageio-ffmpeg）；这些只是创作工具，游玩与构建无需它们：

```text
python scripts/compose-music.py
```

也可只生成指定曲目，保留其他音频文件：

```text
python scripts/compose-music.py harbor workbench mountain
```
