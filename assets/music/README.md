# 深空通信站 · 原创配乐

这四首电子氛围配乐由项目中的 `scripts/compose-music.py` 合成，包含独立的和声、旋律、琶音与立体声回响。没有使用第三方歌曲、录音采样或外部音源。

| 文件 | 曲目 | 使用场景 | 长度 |
| --- | --- | --- | --- |
| `orbit.mp3` | 轨道晨光 | 剧情开场、安静的航段介绍 | 53.33 秒 |
| `code.mp3` | 码间微光 | 前三章的实战练习 | 48.00 秒 |
| `storm.mp3` | 风暴边界 | 第四章起的实战、失败后的调整 | 41.74 秒 |
| `arrival.mp3` | 远方回声 | 成功回信、章节完成 | 56.47 秒 |

以 44.1 kHz 立体声、112 kbps MP3 保存。合成时将释放包络和回响尾音卷回开头，网页通过 AudioBuffer 循环播放。只按需加载当前曲目，初始静音，支持自动选曲与手动固定曲目。自动选曲跟随章节阶段，打开码树、实验和手册等工具窗口，以及中间轮次的发送与结算，均沿用正在播放的旋律。

这些配乐可随本游戏复制、部署和公开播放，不需要额外购买第三方音乐授权。本说明只针对上述四个音乐文件，不替整个项目指定许可证。

重新合成需要 Python、numpy 和 ffmpeg（或 imageio-ffmpeg）；这些只是创作工具，游玩与构建无需它们：

```text
python scripts/compose-music.py
```
